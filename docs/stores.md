# Публикация в магазины приложений

Portfolio+ уже работает как приложение (PWA): его ставят из браузера на Android, Windows, iPhone и Mac.
Магазины добавляют только витрину и доверие. Ниже — что уже готово в коде и что нужно сделать руками,
по порядку от простого к сложному: **Windows → Android → iPhone**.

> **Аккаунты разработчика во всех трёх магазинах можно завести только с 18 лет.** Регистрировать их должен
> взрослый — родитель или научный руководитель проекта. Это его имя будет стоять в магазине как издатель,
> он же принимает соглашения магазина. Команда при этом делает всю работу.

Условия и цены магазинов меняются. Перед регистрацией сверьтесь с их сайтами — ниже указано то, что было
известно на октябрь 2026 года.

## Что уже готово

| Что | Где |
|---|---|
| Манифест: название, описание, иконки (в том числе maskable), цвета заставки, окно без адресной строки | `app/manifest.ts` |
| Скриншоты для окна установки и магазинов: 3 телефонных 1080×1920, 2 широких 1920×1080 | `public/screenshots/` |
| Работа без сети, push-уведомления, камера (сканер грамот) | `public/sw.js`, `components/` |
| Файл для Android `/.well-known/assetlinks.json` (заполняется из переменных окружения) | `app/api/assetlinks/route.ts` |
| Политика конфиденциальности на трёх языках | `/ru/privacy`, `/kz/privacy`, `/en/privacy` |
| Удаление аккаунта внутри приложения | Портфолио → Профиль → «Удалить аккаунт» |

**Перед любой публикацией** добавьте в Vercel переменную `NEXT_PUBLIC_CONTACT_EMAIL` — адрес, на который
пишут пользователи. Все три магазина требуют контакт поддержки, а политика конфиденциальности без него
показывает заглушку.

## 1. Windows — Microsoft Store

Самый простой путь: магазин принимает PWA как есть.

1. Взрослый регистрируется в [Partner Center](https://partner.microsoft.com/dashboard) как **индивидуальный
   разработчик**.
2. В Partner Center: **Apps and games → New product → MSIX or PWA app**, зарезервируйте имя «Portfolio+».
3. Откройте **Product identity** и выпишите три значения: *Package/Identity/Name*, *Publisher* (вида
   `CN=...`) и *Publisher display name*.
4. На [pwabuilder.com](https://www.pwabuilder.com) введите `https://kazakhstanportfolio.vercel.app`,
   **Package for stores → Windows**, вставьте эти три значения и скачайте архив.
5. В Partner Center создайте Submission и загрузите `.msixbundle` из архива. В описании магазина:
   - скриншоты: файлы из `public/screenshots/wide-*.webp` (магазин может попросить PNG — пересохраните);
   - политика конфиденциальности: `https://kazakhstanportfolio.vercel.app/ru/privacy`;
   - возрастной рейтинг: пройдите анкету IARC (насилия, покупок и рекламы в приложении нет;
     пользователи общаются только с ИИ-помощником, не друг с другом).
6. Проверка обычно занимает от нескольких часов до нескольких дней.

Обновлять пакет почти никогда не нужно: приложение показывает сайт, и каждый деплой сразу виден в нём.
Новый пакет нужен только при смене названия, иконки или адреса сайта.

## 2. Android — Google Play

Приложение для Play — это Trusted Web Activity (TWA): полноэкранное окно Chrome с сайтом внутри.

1. Взрослый регистрирует аккаунт в [Play Console](https://play.google.com/console) (разовый взнос $25).
   **У новых личных аккаунтов сначала обязательно закрытое тестирование** (по правилам на 2026 год — не
   меньше 12 тестировщиков в течение 14 дней), и только потом можно выпустить приложение для всех.
   Позовите одноклассников заранее.
2. Выберите имя пакета — его нельзя будет изменить. Например: `kz.portfolioplus.app`.
3. На [pwabuilder.com](https://www.pwabuilder.com): **Package for stores → Android**, укажите имя пакета.
   PWABuilder создаст ключ подписи (`signing.keystore`) и пароли.
   **Ключ и пароли храните в двух надёжных местах вне репозитория** (например, менеджер паролей у ментора).
   Потеряете — не сможете обновлять приложение. В git их класть нельзя.
4. В Play Console создайте приложение и загрузите `.aab` в трек закрытого тестирования.
   Оставьте включённой **Play App Signing** (по умолчанию).
5. Возьмите отпечатки SHA-256 в **Play Console → Test and release → App integrity → App signing**: нужны оба,
   *App signing key certificate* и *Upload key certificate*.
6. В Vercel (Settings → Environment Variables, Production) добавьте:
   - `ANDROID_PACKAGE_NAME` = имя пакета из шага 2;
   - `ANDROID_CERT_SHA256` = оба отпечатка через запятую, в виде `AB:CD:...` (32 пары).

   Сделайте Redeploy и откройте `https://kazakhstanportfolio.vercel.app/.well-known/assetlinks.json` —
   там должны быть имя пакета и отпечатки. Пока их нет, приложение открывается с полоской браузера сверху.
7. Анкеты Play Console:
   - **Data safety.** Перенесите то, что сказано в политике: email, имя и никнейм по желанию, дата рождения,
     фото грамот, сообщения ИИ-помощнику (передаются OpenAI), токен push-уведомлений. Данные шифруются при
     передаче, пользователь может удалить аккаунт в приложении. Рекламы и продажи данных нет.
   - **Удаление аккаунта.** Play требует ещё и веб-ссылку. Укажите сайт и путь «Портфолио → Профиль →
     Удалить аккаунт» или сделайте для этого отдельную страницу.
   - **Целевая аудитория.** Если отметить возраст младше 13 лет, приложение попадёт под правила Families
     (строже проверка и описания). Решение за командой и ментором; ИИ-помощник до 13 лет и так закрыт.
   - **Возрастной рейтинг** — анкета IARC, как для Windows.
8. Через 14 дней тестирования подайте заявку на выпуск в Production.

## 3. iPhone и iPad — App Store

Сейчас на iPhone приложение ставится из Safari: «Поделиться» → «На экран Домой». Push работает с iOS 16.4.
Для App Store нужен отдельный проект, и это самый дорогой шаг:

- **Mac с Xcode** и **Apple Developer Program** ($99 в год, аккаунт взрослого).
- Обёртка **Capacitor** вокруг сайта.
- **Главный риск — правило 4.2 (Minimum Functionality).** Apple отклоняет приложения, которые просто
  показывают сайт. Перед подачей приложению нужны собственные нативные функции через плагины Capacitor:
  - push через APNs (веб-push внутри обёртки не работает);
  - камера для сканера грамот;
  - локальные напоминания о дедлайнах;
  - системное меню «Поделиться».

  Это отдельная работа примерно на одну–две недели.
- Ссылки на сайт, которые открывают приложение (Universal Links), потребуют ещё файл
  `/.well-known/apple-app-site-association`. Его добавим вместе с проектом Capacitor.

Совет: сначала Windows и Android, собрать отзывы и только потом решать, стоит ли iOS своих $99 в год.

## Перед подачей — чек-лист

- [ ] `NEXT_PUBLIC_CONTACT_EMAIL` задан в Vercel, политика показывает адрес.
- [ ] Свой SMTP в Supabase. Без него письма со входом получают только участники команды (см. `docs/auth-email.md`).
- [ ] Казахский текст интерфейса вычитан носителем языка.
- [ ] Скриншоты актуальны: если интерфейс заметно изменился, переснимите их (телефон 1080×1920, широкий
      1920×1080) и замените файлы в `public/screenshots/` с теми же именами.
- [ ] Логотипы организаторов на скриншотах каталога (Samsung и другие) — это их товарные знаки. Если
      магазин придерётся, переснимите экран без них.
- [ ] Описание для магазина на русском, казахском и английском (короткое — до 80 символов, полное — до 4000).
