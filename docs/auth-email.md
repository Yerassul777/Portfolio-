# Письмо со входом: код из 6 цифр, свой шаблон, своя почта

Эти настройки живут в панели Supabase, а не в коде. Сделать их может только владелец проекта.

## 1. Код из 6 цифр

Supabase → **Authentication → Sign In / Providers → Email** → **Email OTP Length** = `6` → Save.

Приложение принимает код любой длины, менять в коде ничего не нужно.

## 2. Шаблон письма

Supabase → **Authentication → Emails → Templates**. Шаблон нужен в двух местах: новый пользователь получает «Confirm sign up», вернувшийся — «Magic link».

| Поле | Значение |
|---|---|
| Subject | `Код входа в Portfolio+` |
| Body | всё содержимое [`supabase/templates/sign-in-code.html`](../supabase/templates/sign-in-code.html) |

В шаблоне написано «код действует 1 час». Если поменяете **Email OTP Expiration**, поправьте и эту фразу.

## 3. Своя почта (SMTP) — важно

Встроенная почта Supabase отправляет письма **только адресам участников команды проекта** в Supabase. Ученики без доступа к проекту кода не получат: вход по почте у них не работает. Вход через Google работает и без этого.

Свой SMTP в Supabase бесплатен на любом тарифе. Платить не нужно, нужен почтовый сервис. Письма тогда приходят от вашего имени, а не от Supabase.

Варианты без своего домена:

- **Brevo** (бесплатно 300 писем в день). Подтверждаете один адрес отправителя, в разделе SMTP & API создаёте SMTP-ключ.
- **Gmail** (около 500 писем в день). В аккаунте Google включаете двухэтапную проверку, создаёте «Пароль приложения». Сервер `smtp.gmail.com`, порт `465`.

Затем Supabase → **Authentication → Emails → SMTP Settings** → Enable custom SMTP:

- Sender email — адрес отправителя;
- Sender name — `Portfolio+`;
- host, port, user, password — из сервиса выше.

После этого поднимите лимит писем: **Authentication → Rate Limits → emails per hour**. Со своим SMTP по умолчанию 30 в час.

Пароль SMTP никуда не записывайте и никому не пересылайте: он хранится только в Supabase.
