# Контракт производительности

Сайт должен быстро открываться на среднем Android по мобильной сети в Казахстане. Поэтому пороги ниже проверяются автоматически на каждый push и pull request (`.github/workflows/performance.yml`). Если изменение их нарушает, проверка падает.

| Что | Порог | Чем проверяется |
|---|---|---|
| JavaScript первого экрана, gzip | ≤ 200 КБ на страницу | `scripts/check-js-budget.mjs` |
| LCP (главный элемент на экране) | ≤ 2,5 с | Lighthouse, мобильный профиль |
| CLS (прыжки вёрстки) | ≤ 0,1 | Lighthouse |
| Performance | ≥ 90 | Lighthouse |
| Accessibility, Best practices, SEO | ≥ 95 | Lighthouse |
| TBT (блокировка главного потока) | ≤ 200 мс, только предупреждение | Lighthouse |

Lighthouse запускается 3 раза, учитывается медиана. Замер идёт с настоящим замедлением сети и процессора (`throttlingMethod: devtools`).

**Почему не симуляция.** Это режим Lighthouse по умолчанию. При встроенном CSS он ошибочно считает, что отрисовка ждёт весь JavaScript, и завышает LCP вдвое.

**TBT — только предупреждение.** Это лабораторная замена INP, и на машинах GitHub она нестабильна.

## Как проверить у себя

```bash
pnpm build && pnpm start -p 3100
node scripts/check-js-budget.mjs http://localhost:3100 200 /ru /ru/competitions
npx @lhci/cli@0.15.1 autorun
```

## Что держит сайт в бюджете

- **CSS встроен в HTML** (`experimental.inlineCss`). Отдельного запроса, блокирующего отрисовку, нет.
- **Панели ИИ и заметок, окно фильтров и окно возможности грузятся по требованию** (`next/dynamic`). Код панелей подгружается заранее, когда браузер свободен.
- **supabase-js загружается после первой отрисовки**, когда браузер свободен.
- **Данные каталога кэшируются на сервере на 60 секунд** (`lib/server-data.ts`). Страница не ждёт ответа базы.
- **Внимательно с импортами в `loading.tsx`, `not-found.tsx`, `error.tsx` и `global-error.tsx`.** Эти файлы входят в JavaScript каждой страницы, и всё, что они импортируют, тоже. Так уже было дважды: `not-found.tsx` тянул весь словарь через `SiteShell`, а `loading.tsx` — второй экземпляр каталога через `catalogue.tsx`. Если бюджет вдруг вырос, сначала ищите такой импорт.
- **Только CSS-анимации `opacity` и `transform`.** Карточки появляются с анимацией лишь после смены выдачи, а при `prefers-reduced-motion` анимации нет вовсе.
